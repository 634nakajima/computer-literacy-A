## 3. Learn Word Formatting

Let's learn each formatting technique step by step, using the sample as a reference.

### 3-1. Changing the Font

How to change the font (typeface) of text.

**Steps:**

1. **Select the text** you want to change by dragging over it
2. Click the **Font name box** in the **"Home" tab** (the box showing the current font name near the top-left)
3. Type the font name you want or choose from the list

**Common Fonts:**

| Font | Use | Features |
|------|-----|----------|
| **Yu Gothic** | Titles & headings | Bold and eye-catching. Good for short text |
| **Yu Mincho** | Body text | Easy to read. Good for long passages |
| **Times New Roman** | English body text | Standard serif font |
| **Arial** | English headings | Standard sans-serif font |

::: tip Serif vs. Sans-serif
- **Serif fonts** (Yu Mincho, Times New Roman) → Use for body text (long passages)
- **Sans-serif fonts** (Yu Gothic, Arial) → Use for titles and headings (to stand out)
:::

### 3-2. Changing Font Size

How to change the size of text.

**Steps:**

1. **Select** the text you want to resize
2. Click the **Font size box** in the **"Home" tab** (the box showing a number)
3. Type a number or choose from the list

**Sizes Used in the Sample:**

| Element | Font Size |
|---------|----------|
| Title | **14pt** |
| Body text | **10.5pt** (Word's default) |

### 3-3. Text Alignment

Set whether text is aligned to the left, center, right, or both edges. In the sample, the date, department, and name are **right-aligned**, while the body text is **justified**.

**▼ Header section of the sample (note the alignment of date, title, and name)**

![Sample header section](/images/lesson03/sample-header.png)

**Steps:**

1. **Place your cursor** in the line (paragraph) you want to change, or select multiple lines
2. Click the alignment buttons in the **"Home" tab** → **"Paragraph" group**

**Types of Alignment:**

| Button | Name | Use |
|--------|------|-----|
| ≡ (left) | **Left align** | Regular text |
| ≡ (center) | **Center align** | Titles |
| ≡ (right) | **Right align** | Dates, names |
| ≡ (both) | **Justify** | Body text (both edges align evenly) |

::: info What is "Justify"?
Justified alignment makes both the left and right edges of each line align neatly. This gives the document a polished appearance, so it's commonly used for body text in reports and essays.
:::

### 3-4. First-line Indent

"Indenting" means shifting the first line of a paragraph slightly to the right. In Japanese writing, it is standard to indent the first line of every paragraph by one character width. The sample document shows this clearly.

**▼ Body section of the sample (note the first-line indents and numbered list)**

![Sample body section](/images/lesson03/sample-body.png)

**Method 1: Using the Space key**

1. Place your cursor at the beginning of the paragraph
2. Press the **full-width space** key once

**Method 2: Using Indent Settings (recommended)**

1. Place your cursor in the paragraph you want to indent (or select multiple paragraphs)
2. In the **"Home" tab** → **"Paragraph" group**, click the **small arrow** (dialog launcher) in the bottom-right corner
3. The "Paragraph" dialog box opens
4. Under the **"Indents and Spacing"** tab, set **"Special"** to **"First line"**
5. Set the **"By"** value to **1 character** (or approximately 10.5pt)
6. Click "OK"

::: warning Note
Indentation is needed **at the start of every paragraph**. Check the sample document to see which paragraphs are indented.
:::

### 3-5. Paragraph Numbering (Numbered Lists)

How to add numbers to a list. In the sample document, this feature is used for listing goals.

**Steps:**

1. **Select** the lines you want to number (you can select multiple lines)
2. In the **"Home" tab** → **"Paragraph" group**, click the **"Numbering" button** (the 1. 2. 3. icon)
3. Numbers are automatically added

::: tip Changing the Number Style
Click the **▼** arrow next to the Numbering button to choose different styles (1. 2. 3. / ① ② ③ / a. b. c., etc.).
:::

### 3-6. Adjusting Spacing

Adding appropriate space between paragraphs makes a document easier to read. Here, you'll add spacing between the student ID/name and the body text, and before and after the numbered list.

**Add spacing between the student name and body text:**

1. Place your cursor on the student ID & name line
2. Click the **Line and Paragraph Spacing** icon (<img src="/images/line-spacing-icon.png" alt="Line and Paragraph Spacing" style="height:1.2em;vertical-align:middle;display:inline;margin:0;">) in the **"Home" tab**
3. Click **"Add Space After Paragraph"** from the menu

**Add spacing before and after the numbered list:**

1. Place your cursor on the **first line** of the numbered list
2. Click the **Line and Paragraph Spacing** icon and select **"Add Space Before Paragraph"**
3. Place your cursor on the **last line** of the numbered list
4. Click the **Line and Paragraph Spacing** icon and select **"Add Space After Paragraph"**

**To set a specific spacing value:**

1. Place your cursor in the target paragraph
2. Click the **Line and Paragraph Spacing** icon → **"Line Spacing Options..."**
3. Under the **"Spacing"** section, change **"After"** to **"12pt"** or **"6pt"**
4. Click **"OK"**

::: tip Spacing Guidelines
**12pt** (about 4mm) is roughly equivalent to one line of space. If it feels too wide, try reducing it to **6pt**.
:::

## 4. Create Your Own Document

Using the formatting skills you've learned, create a document with the **same layout** as the sample — but with your own content.

### 4-1. Choose a Topic

Pick one topic from the list below and write an essay about it. You're free to choose any topic, but here are some suggestions:

- My goals for university life
- My hobbies or talents
- My future dream
- Something I'm interested in lately
- Other (free topic)

### 4-2. Document Structure

Create your document with the same structure as the sample:

1. **Date** (right-aligned)
2. **Title** (Yu Gothic, 14pt)
3. **Department name** (right-aligned)
4. **Student ID & Name** (right-aligned)
5. **Body text**
   - Justified alignment
   - First-line indent on each paragraph
   - Write multiple paragraphs (aim for at least 300 characters total)
6. **Numbered list** (use paragraph numbering to create a numbered list)

### 4-3. Change the Page Setup

Match the sample's page settings:

1. Go to **"Layout" tab** → **"Margins"**
2. Select **"Moderate"** from the list

### 4-4. Formatting Checklist

As you work, check off each item:

- [ ] Date is **right-aligned**
- [ ] Title is in **Yu Gothic, 14pt**
- [ ] Department, student ID, and name are **right-aligned**
- [ ] Body text is **justified**
- [ ] Paragraphs have a **first-line indent**
- [ ] List items use **paragraph numbering**
- [ ] Margins are set to **"Moderate"**
- [ ] **Spacing** is added between the student name and body text
- [ ] **Spacing** is added before and after the numbered list

Use the **Manus AI** skill to check the formatting of the document you created in section 4.

1. Go to [manus.im](https://manus.im)
2. Click **"Log in"** on the left side of the screen
3. Click **"Continue with Google"**
4. Enter your university Gmail address (`@t-kougei.ac.jp`) and password to sign in

::: warning Free plan usage limits
Manus's free plan uses a **credit-based usage limit**. Once your credits run out, you won't be able to use it further. Avoid unnecessary back-and-forth and work efficiently.
:::

### 5-2. Install the Formatting Checker Skill

**Download the skill:**
[report-formatter-docx.zip](/report-formatter-docx.zip)

**Installation steps:**

1. Download **report-formatter-docx.zip** from the link above
2. In Manus, click **"Settings"** (bottom-left) → **"Skills"** → **"+ Add"** → **"Upload Skill"**
3. Select the downloaded file to upload it
4. Open the added **"Formatting Checker"** skill

### 5-3. Check Your Document

1. **Attach the Word file** you created in section 4 to the chat and send it
2. Review the formatting issues the AI points out
3. Go back to your Word document and fix the flagged items

::: warning Don't take AI feedback at face value
AI suggestions are **not always accurate or appropriate**. Use your own judgment to decide whether each issue is a real problem before making changes.
:::

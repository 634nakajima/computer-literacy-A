## 1. Gmail — メールの基本

大学では、Gmailを使って教員や事務局とやり取りします。ここでは **署名の設定** と **フォーマルなメールの書き方** を学びます。

### 1-1. Gmailにログインする

1. ブラウザで [Gmail](https://mail.google.com/) を開く
2. 大学のGoogleアカウント（`i学籍番号@st.t-kougei.ac.jp`）でログインする

::: tip ログインできない場合
大学のメールアドレスとパスワードが分からない場合は、情報センターの案内を確認してください。
:::

### 1-2. 署名を設定する

署名とは、メールの末尾に自動で追加される「自分の情報」のことです。ビジネスメールでは署名を付けるのがマナーです。

**設定手順：**

1. Gmailの画面右上の **歯車アイコン** ⚙️ をクリック
2. **「すべての設定を表示」** をクリック
3. **「全般」** タブを下にスクロールし、**「署名」** セクションを見つける
4. **「+ 新規作成」** をクリックし、署名名を入力（例：「大学用」）
5. 以下のような署名を入力する：

```
東京工芸大学芸術学部
インタラクティブメディア学科1年
学籍番号 2024000
工芸 太郎
mail: i2024000@st.t-kougei.ac.jp
```

6. 「デフォルトの署名」で「新規メール用」と「返信/転送用」の両方にこの署名を選択
7. ページ最下部の **「変更を保存」** をクリック

::: warning 注意
学籍番号・氏名・メールアドレスは自分のものに置き換えてください。
:::

### 1-3. フォーマルなメールを作成・送信する

大学では教員にメールを送る機会が多くあります。社会に出てからも使える正しいメールの書き方を身につけましょう。

**メールの構成：**

| 要素 | 内容 |
|------|------|
| **宛先** | `m.nakajima@int.t-kougei.ac.jp` |
| **件名** | `課題１（2024000 工芸太郎）` |
| **本文** | 下記参照 |

**本文の例：**

```
中島先生

お世話になっております。
インタラクティブメディア学科1年の工芸太郎です。

これまでパソコンはあまり利用したことがないので、
この授業で使い方を覚えていきたいと思います。
何卒よろしくお願い申し上げます。

（以下、署名が自動で入ります）
```

**フォーマルメールのポイント：**

- 冒頭に **宛名**（〇〇先生）を書く
- **「お世話になっております。」** で始める（初回は「はじめまして。」でもOK）
- **自分の所属と名前** を名乗る
- 本文は **簡潔に、丁寧な言葉遣い** で書く
- 結びは **「よろしくお願いいたします。」** などで締める

::: details よくあるNG例
- 件名が空 → 件名には用件と名前を入れましょう
- 「中島さんへ」→ 大学では「先生」を使いましょう
- いきなり用件 → 挨拶と名乗りを忘れずに
- 「了解です」→ 目上の人には「承知いたしました」を使いましょう
:::

### 1-4. スマートフォンにGmailアプリをインストールする

大学のメールをスマホでも受け取れるようにしましょう。

1. [大学の設定ガイド](https://www.cc.t-kougei.ac.jp/mail/setup-s-2/#item2) を参考にする
2. Gmailアプリをインストール（すでにインストール済みの場合はアカウント追加）
3. 大学のGoogleアカウントでログインする

## 2. Microsoft 365 — アカウント作成とWord

大学では、レポートや文書の作成にMicrosoft Word を使います。まず Microsoft 365 のアカウントを準備しましょう。

### 2-1. Microsoftアカウントを作成する

1. [大学のMicrosoft 365案内ページ](https://www.cc.t-kougei.ac.jp/services/manuals/student_advantage_office365proplus/) を開く
2. 手順に従い、大学提供のMicrosoft 365アカウントを作成する
3. パスワードは忘れないようにメモしておく

::: tip 在学中は無料！
東京工芸大学の学生は在学中、Microsoft 365（Word・Excel・PowerPointなど）を無料で利用できます。
:::

### 2-2. Wordで自己紹介文書を作成する

1. デスクトップのWordアプリ、または [Microsoft 365 Online](https://www.office.com/) からWordを起動する
2. **「白紙の文書」** をクリックして新規文書を作成
3. 以下の内容を含む **自己紹介文書** を作成する：

**記載する内容：**

- 氏名
- 学籍番号
- 学科・学年
- 出身地
- 趣味・特技
- この授業で学びたいこと
- （後でタイピングスコアも追記します）

::: tip 書式のヒント
- タイトルは **太字** にしたり、**フォントサイズを大きく** すると見やすくなります
- まだ細かい書式は気にしなくてOK — Word の詳しい使い方は第3回で学びます
:::

4. ファイル名を **「自己紹介_学籍番号」**（例：`自己紹介_2024000`）として保存する

## 3. タイピング練習

PCを使いこなすには、キーボード入力のスピードと正確性が欠かせません。今日から毎回練習して、少しずつ上達していきましょう。

### 3-1. e-typingでタイピング練習をする

1. [e-typing ローマ字タイピング](https://www.e-typing.ne.jp/roma/check/) にアクセスする
2. **「腕試しレベルチェック」** を始める
3. 画面に表示される文章を、できるだけ正確に入力する
4. 結果画面で **スコア** と **レベル** を確認する

**スコアの目安：**

| レベル | スコア | 説明 |
|--------|--------|------|
| E〜D | 0〜100 | 練習あるのみ！毎日少しずつ取り組もう |
| C | 100〜200 | 一般的なレベル。正確さを意識しよう |
| B | 200〜300 | なかなかの腕前！スピードも上げていこう |
| A以上 | 300〜 | 素晴らしい！さらなる高みを目指そう |

### 3-2. ベストスコアを記録する

1. 何度か練習して、**ベストスコア** をメモする
2. 先ほど作成した **自己紹介のWord文書** に以下を追記する：
   - タイピングスコア
   - レベル（E〜S）
   - 感想やこれからの目標

::: tip タイピング上達のコツ
- **ホームポジション**（左手人差し指を `F`、右手人差し指を `J`）を意識する
- 最初は **スピードより正確さ** を重視する
- 毎日5〜10分の練習を続けるのが一番効果的
- キーボードを見ないで打つ **ブラインドタッチ** を目指そう
:::

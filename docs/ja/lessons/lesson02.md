## 1. Gmail — メールの基本

大学では、Gmailを使って教員や事務局とやり取りします。ここでは **署名の設定** と **フォーマルなメールの書き方** を学びます。

### 1-1. Gmailにログインする

1. ブラウザで [Gmail](https://mail.google.com/) を開く
2. 大学のGoogleアカウント（`i学籍番号@st.t-kougei.ac.jp`）でログインする

::: tip ログインできない場合
大学のメールアドレスとパスワードが分からない場合は、情報センターの案内を確認してください。
:::

### 1-2. 署名を設定する

署名とは、メールの末尾に自動で追加される「自分の情報」のことです。ビジネスメールでは署名を付けるのがマナーです。

**設定手順：**

1. Gmailの画面右上の **歯車アイコン** ⚙️ をクリック
2. **「すべての設定を表示」** をクリック
3. **「全般」** タブを下にスクロールし、**「署名」** セクションを見つける
4. **「+ 新規作成」** をクリックし、署名名を入力（例：「大学用」）
5. 以下のような署名を入力する：

```
東京工芸大学芸術学部
インタラクティブメディア学科1年
学籍番号 2024000
工芸 太郎
mail: i2024000@st.t-kougei.ac.jp
```

6. 「デフォルトの署名」で「新規メール用」と「返信/転送用」の両方にこの署名を選択
7. ページ最下部の **「変更を保存」** をクリック

::: warning 注意
学籍番号・氏名・メールアドレスは自分のものに置き換えてください。
:::

### 1-3. フォーマルなメールを作成・送信する

大学では教員にメールを送る機会が多くあります。社会に出てからも使える正しいメールの書き方を身につけましょう。

**メールの構成：**

| 要素 | 内容 |
|------|------|
| **宛先** | `m.nakajima@int.t-kougei.ac.jp` |
| **件名** | `課題１（2024000 工芸太郎）` |
| **本文** | 下記参照 |

**本文の例：**

```
中島先生

お世話になっております。
インタラクティブメディア学科1年の工芸太郎です。

これまでパソコンはあまり利用したことがないので、
この授業で使い方を覚えていきたいと思います。
何卒よろしくお願い申し上げます。

（以下、署名が自動で入ります）
```

**フォーマルメールのポイント：**

- 冒頭に **宛名**（〇〇先生）を書く
- **「お世話になっております。」** で始める（初回は「はじめまして。」でもOK）
- **自分の所属と名前** を名乗る
- 本文は **簡潔に、丁寧な言葉遣い** で書く
- 結びは **「よろしくお願いいたします。」** などで締める

::: details よくあるNG例
- 件名が空 → 件名には用件と名前を入れましょう
- 「中島さんへ」→ 大学では「先生」を使いましょう
- いきなり用件 → 挨拶と名乗りを忘れずに
- 「了解です」→ 目上の人には「承知いたしました」を使いましょう
:::

### 1-4. スマートフォンにGmailアプリをインストールする

大学のメールをスマホでも受け取れるようにしましょう。

1. [大学の設定ガイド](https://www.cc.t-kougei.ac.jp/mail/setup-s-2/#item2) を参考にする
2. Gmailアプリをインストール（すでにインストール済みの場合はアカウント追加）
3. 大学のGoogleアカウントでログインする

## 2. AIにメールの下書きを依頼する

セクション1で学んだフォーマルなメールの書き方を、AI（Claude）に教えて下書きを作らせてみましょう。AIはとても便利なツールですが、**正しい指示（プロンプト）を出す** ことが重要です。

### 2-1. Claudeにアクセスする

1. ブラウザで [Claude](https://claude.ai/) を開く
2. Googleアカウント（大学のアカウントでOK）でログインする

::: tip Claudeとは？
Claude（クロード）は、Anthropic社が開発した対話型AIアシスタントです。文章の作成、要約、翻訳など、さまざまなタスクを手伝ってくれます。
:::

### 2-1-1. GmailをClaudeに接続する

ClaudeとGmailを連携させると、メールの内容を直接Claudeに読み込ませたり、下書きを保存したりできるようになります。以下の手順で設定しましょう。

1. 左サイドバーの **「カスタマイズ」** をクリック
2. **「コネクタ」** タブをクリック（またはページ内の **「アプリを接続」** ボタンをクリック）
3. 一覧から **「Gmail」** をクリック
4. **「接続」** をクリックし、表示されたGoogleアカウント選択画面で **大学のアカウント** を選ぶ
5. Googleの権限確認画面で **「許可」** をクリック
6. Claudeの画面に戻り、Gmailが接続済みになっていれば完了

::: warning 大学のアカウントを使うこと
個人のGmailアカウントではなく、大学のGoogleアカウント（`i学籍番号@st.t-kougei.ac.jp`）で認証してください。
:::

::: tip 接続後にできること
- 「先生から来たメールを要約して」など、自然な言葉でメールを検索・参照できる
- 作成した下書きをGmailに保存できる（自動送信はされません）
:::

### 2-2. メールの下書きを依頼する

以下の状況を想定して、Claudeにメールの下書きを依頼してみましょう。

**想定シチュエーション：**

> あなたはコンピュータリテラシーAの課題の提出期限に間に合いそうにありません。体調不良で数日パソコンに向かえなかったことが理由です。担当教員の中島先生に、提出期限の延長をお願いするメールを書きたいと思っています。

**やってみよう：**

1. まずは **何も指示せず** に、以下のようにだけ入力してみましょう：

```
課題の提出期限を延長してほしいというメールを書いて
```

2. AIの返答を確認してみましょう。おそらく、以下のどちらかの反応が返ってきます：
   - **「どんな状況ですか？」と聞き返してくる** → 情報が足りないとAIが判断したサインです
   - **複数のパターンを提示してくる** → AIが自力で補おうとした結果です

3. AIが「何を聞いてきたか」「何を自分で補おうとしたか」に注目してください。それが **プロンプトに最初から含めるべきだった情報** です。

### 2-3. プロンプトを改善する

AIが聞き返してきた内容を手がかりに、指示を書き直してみましょう。**AIの質問リスト＝必要な情報リスト** と考えると、何を追加すべきかが見えてきます。

**プロンプトに含めるべき情報：**

| 要素 | 内容の例 |
|------|----------|
| 自分の立場 | 東京工芸大学 インタラクティブメディア学科 1年 |
| 宛先 | 中島先生（コンピュータリテラシーAの担当教員） |
| 用件 | 課題の提出期限の延長をお願いしたい |
| 理由 | 体調不良で数日パソコンに向かえなかった |
| メールの形式 | フォーマルな大学のメール（セクション1で学んだ形式） |

**改善したプロンプトの例：**

```
以下の条件でフォーマルなメールの下書きを作成してください。

・差出人：東京工芸大学 芸術学部 インタラクティブメディア学科1年 工芸太郎
・宛先：中島先生（コンピュータリテラシーAの担当教員）
・用件：課題の提出期限を延長してほしい
・理由：体調不良（発熱）で数日間パソコンに向かえなかったため
・形式：大学の教員に送るフォーマルなメール
・冒頭に宛名、挨拶、自己紹介を入れ、結びは丁寧にしてください
・Gmail上に下書きを作成してください
```

3. 改善前と改善後を見比べて、**AIが追加で質問してこなくなったか**、**1回でほしい出力が得られたか** を確認しましょう

::: tip AIとのやり取りを減らすことがゴール
AIは曖昧な指示でも何かしら答えようとします。ただし、情報が足りないと何度も聞き返してきたり、見当違いの内容を出力したりします。最初から必要な情報を揃えておくと、**1回のやり取りで目的の出力が得られる**ようになります。
:::

### 2-4. 出力をチェックして修正する

AIが書いた文章は、**そのまま送ってはいけません**。必ず自分で内容を確認しましょう。

**チェックポイント：**

- [ ] 先生の名前は正しいか？
- [ ] 自分の所属・学籍番号・名前は正しいか？
- [ ] 敬語の使い方は適切か？（大げさすぎないか、くだけすぎていないか）
- [ ] 嘘の情報が含まれていないか？
- [ ] 自分の言葉として自然に読めるか？

::: warning AIを使うときの大切な心構え
- AIの出力は **下書き（たたき台）** です。最終的な責任は自分にあります
- AIは **もっともらしい嘘** をつくことがあります（ハルシネーション）。事実は必ず自分で確認しましょう
- 個人情報（学籍番号や電話番号など）をAIに入力する際は注意が必要です
:::

### 2-5. 完成したメールを送信する

1. AIの出力をもとに、自分で修正・調整して **最終版のメール** を完成させる
2. セクション1で学んだ手順で、Gmailから教員宛に送信する
   - 宛先：`m.nakajima@int.t-kougei.ac.jp`
   - 件名：`課題２（学籍番号 氏名）`

## 3. タイピング練習

PCを使いこなすには、キーボード入力のスピードと正確性が欠かせません。今日から毎回練習して、少しずつ上達していきましょう。

### 3-1. e-typingでタイピング練習をする

1. [e-typing ローマ字タイピング](https://www.e-typing.ne.jp/roma/check/) にアクセスする
2. **「腕試しレベルチェック」** を始める
3. 画面に表示される文章を、できるだけ正確に入力する
4. 結果画面で **スコア** と **レベル** を確認する

**スコアの目安：**

| レベル | スコア | 説明 |
|--------|--------|------|
| E〜D | 0〜100 | 練習あるのみ！毎日少しずつ取り組もう |
| C | 100〜200 | 一般的なレベル。正確さを意識しよう |
| B | 200〜300 | なかなかの腕前！スピードも上げていこう |
| A以上 | 300〜 | 素晴らしい！さらなる高みを目指そう |

### 3-2. ベストスコアを記録する

1. 何度か練習して、**ベストスコア** をメモしておく
2. スコアとレベルは **次回（第3回）** の提出物で使います

::: tip タイピング上達のコツ
- **ホームポジション**（左手人差し指を `F`、右手人差し指を `J`）を意識する
- 最初は **スピードより正確さ** を重視する
- 毎日5〜10分の練習を続けるのが一番効果的
- キーボードを見ないで打つ **ブラインドタッチ** を目指そう
:::

# 第4回 AIと一緒にレポートを書く

## 今回の目標

- レポートと感想文の違いを理解する
- AIとの対話を通じて、レポートの「考え方」を体験する
- テーマ選定 → 構成設計 → 主張と根拠の検討 → 下書き生成の流れを身につける
- 授業外課題としてレポートを完成させる

::: info この授業のねらい
今回の演習は、**AIを使った対話的なレポート作成を実際に体験すること**が目的です。体験した上で「自分にはこのやり方が合っている」「もっと自分で考えて書きたい」など、**自分に合ったやり方を見極めてください**。どちらの選択も正解です。
:::

::: warning AIの出力を鵜呑みにしない
AIが提案する構成・表現・根拠は、**必ずしも正確・適切であるとは限りません**。事実誤認や的外れな分析が含まれる場合もあります。AIの出力はあくまで「たたき台」として使い、内容が自分の意図や事実と合っているかを**自分の目で確認・修正しながら**進めましょう。
:::

## 1. レポートとは何か

### 1-1. 感想文とレポートの違い

| | 感想文 | レポート |
|--|--------|---------|
| **目的** | 自分が感じたことを伝える | 読者を「なるほど」と納得させる |
| **主語** | 「私は〜と感じた」 | 「〇〇は〜であると考えられる」 |
| **根拠** | なくてもよい | **必須**（データ・事例・比較など） |
| **構成** | 自由 | 序論→本論→結論の論理的な流れ |
| **文体** | ですます調でもOK | である調で統一 |

### 1-2. AI時代のレポートの書き方

AIは文章を書くことが得意です。しかし、**何について、どんな主張を、どんな根拠で書くか**を決めるのは人間の仕事です。

この授業では、従来の「体裁のルールを覚える」アプローチではなく、**AIと対話しながらレポートの思考プロセスを体験する**アプローチを取ります。

```
従来：ルールをたくさん覚える → 覚えきれない → 定着しない

今回：AIと対話しながら考える → 思考の流れを体験する → 考える力が残る
```

::: tip 体裁のルールは覚えなくていい？
レポートには確かに守るべき体裁ルールがあります（このページ末尾の付録を参照）。大事なのは、まず**何を書くかを自分で考えること**です。体裁の整え方は付録と「5. Word操作ガイド」を参照してください。
:::

## 2. 今回のレポート課題

### テーマ

> **あなたが最も影響を受けたメディア作品（ゲーム・映像・音楽・アプリ・Webサービスなど）が持つ表現の仕組みを分析し、なぜ人を惹きつけるのかを論ぜよ**

### 要件

| 項目 | 内容 |
|------|------|
| **テーマ** | 自分が強く影響を受けたメディア作品を1つ選ぶ |
| **内容** | 単なる感想ではなく、**分析**と**主張**を展開する |
| **分量** | Word文書3〜4ページ |
| **図表** | 作品のスクリーンショットや図を最低1つ含める |
| **参考文献** | 最低1つ以上の参考文献を引用する |
| **提出** | 授業内で指示された方法で提出 |
| **期限** | 次回授業日前日まで |

::: warning 「好きだから」だけでは不十分
「この作品が好きです。面白いです。」は感想文です。レポートでは「**なぜ**面白いのか」「**どのような仕組み**が人を惹きつけているのか」を分析し、根拠を示して論じる必要があります。
:::

## 3. AIとの対話でレポートを作る（授業内演習）

今日の授業では、**Manus AI**（専用スキル）を使ってレポートの骨格を対話的に作り上げます。

### 3-1. 「レポート伴走AI」を準備する

まず、専用スキルをダウンロードして Manus にインストールします。

**スキルのダウンロード：**
[report-writing-companion.zip](/report-writing-companion.zip)

**インストール手順：**

1. 上のリンクから **report-writing-companion.zip** をダウンロードする
2. [manus.im](https://manus.im) にアクセスし、アカウントでログインする（第3回で作成済み）
3. 画面左下の **「設定」→「スキル」→「＋追加」→「スキルをアップロード」** を選択する
4. ダウンロードした zip ファイルを選択してアップロードする
5. 追加された「**レポート伴走AI**」スキルを開く
6. チャット欄に「**始めてください**」と入力して送信する

::: warning 無料プランの利用上限に注意
Manusの無料プランには**クレジット制の利用上限**があります。クレジットを使い切ると、それ以上使えなくなります。無駄なやり取りを減らし、演習を計画的に進めましょう。
:::

::: warning Enterキーに注意
チャット欄では **Enter** を押すとメッセージが送信されます。改行したいときは **Shift + Enter** を使ってください。
:::

### 3-2. Phase 1 — テーマを選ぶ（10〜15分）

AIに「始めてください」と伝えると、以下のような質問が来ます：

> 「最近、時間を忘れて没頭したメディア作品は何ですか？」

**やること：**
- 自分が本当に好きな作品を正直に答える
- 「どこが好きか」「他の作品と何が違うか」をAIに聞かれるので、自分の言葉で答える
- AIが分析の切り口を提案してくれるので、一番しっくりくるものを選ぶ

::: details 選ぶ作品の例
- スマホゲーム（原神、プロセカ、モンスト、ポケモンGOなど）
- コンソールゲーム（ゼルダ、マイクラ、あつ森、スプラトゥーンなど）
- SNS・アプリ（TikTok、Instagram、Spotify、LINEなど）
- 映像作品（Netflix作品、YouTuber、MV、アニメなど）
- 音楽体験（ライブ配信、音楽ゲーム、AIプレイリストなど）
- Webサービス（Canva、Notion、Pinterest、Figmaなど）
:::

### 3-3. Phase 2 — 構成を設計する（10〜15分）

テーマが決まったら、AIがレポートの構成案を提案します。

**やること：**
- 提案された構成を読み、「この流れで読者に伝わるか？」を考える
- 気になる点があればAIに「ここはこう変えたい」と伝える
- 特に「**はじめに**で立てた問いに、**おわりに**で答えられているか」を確認する

### 3-4. Phase 3 — 主張と根拠を詰める（20〜25分）

ここが最も重要なフェーズです。各セクションについてAIと議論します。

AIは各セクションの性質に応じて異なる問いかけをしてきます。共通して重要なのは、以下の**3つの問い**です：

| 問い | 意味 | 例 |
|------|------|-----|
| **なぜ？** | 理由・根拠を掘り下げる | 「なぜそう言えるの？」 |
| **具体的には？** | 抽象的な話を具体化する | 「具体的にどの場面で？」 |
| **どうやって？** | 仕組みや方法を明らかにする | 「それはどんな仕組みで実現されている？」 |

**やること：**
- 自分の言葉で答える（うまく言えなくてOK）
- AIが学術的な表現に変換してくれるので、意味が合っているか確認する
- 答えに詰まったときは正直に言う → AIがヒントやリサーチを手伝ってくれる

::: info 「根拠」の種類
- **具体例**：「このゲームでは、敵を倒すたびにエフェクトと効果音が出る」
- **比較**：「類似のゲームAではこの機能がないが、Bにはある。その差が体験に影響している」
- **データ・調査**：「この作品は発売から1年で1000万本を売り上げた」
- **理論・概念**：「フロー理論によれば、難易度とスキルのバランスが没入感を生む」
:::

### 3-5. Phase 4 — 下書きを生成する（10〜15分）

Phase 3で議論した内容をもとに、セクションごとに下書きを生成します。

**やること：**
- AIが生成した下書きを読み、「自分の言いたいことと合っているか」を確認する
- 合っていない部分は「ここはこうじゃなくて…」「自分ならこう言う」と**修正を依頼する、または自分で書き直す**
- AIの出力をそのまま完成版にせず、**自分の文章として自然に読めるまで修正を繰り返す**
- すべてのセクションが揃ったら、全体を通して読む
- 内容に納得したら、テキストを**コピーしてWordに貼り付ける**

::: tip ManusのレポートをWordに書き出す手順
1. セクションがすべて揃ったら、Manusに「**Word形式で書き出してください**」と伝える
2. Manusが生成した Word ファイル（.docx）を**ダウンロード**する
3. Word で開いて、図表の挿入や体裁の調整を行う
:::

### 3-6. Phase 5 — 対話サマリーを出力する

最後に、AIに「対話サマリーを出力してください」と伝えます。以下が出力されます：

- 選んだ作品とテーマ
- レポートの構成と各セクションの要約
- 各セクションの主張と根拠
- 対話を通じて気づいたこと

このサマリーは、自分がどのようにテーマを選び、何を考え、どう論理を組み立てたかの**振り返り記録**になります。対話が終わったら、チャット画面右上の **「共有」** からリンクを取得しておきましょう。このリンクが提出物の一部になります。

## 4. 授業外課題 — レポートを完成させる

### 4-1. やること

授業内の演習でAIと対話しながら作成した内容をもとに、自分に合ったやり方でレポートを仕上げましょう。

::: tip 仕上げ方は自分で選んでいい
- **AIをそのまま活用したい場合**：Phase 4で生成・修正した本文をベースに、図表・参考文献・体裁を整えて完成させる
- **自分でもっと書きたい場合**：授業内の対話で得た構成や視点を参考にしながら、自分の言葉で書き直す・加筆するなど、自分のペースで仕上げてかまわない

どちらの進め方でも、最終的なレポートの質が大切です。
:::

授業外では以下の仕上げ作業を行います。

1. **図表を入れる**
   - 作品のスクリーンショットや関連画像を最低1つ含める
   - 図には番号とタイトルをつける（例：「図1 ○○の操作画面」）
   - 本文中で「図1は〜を示している」のように言及する
   - 手順は後述の「5. レポートの体裁を整える — Word操作ガイド」を参照
2. **参考文献を追加する**
   - レポート内で参照した資料・Webサイトを文末にリストとして記載する
   - 本文中の引用箇所に `[1]` のように引用番号を振る
3. **体裁を整える**
   - 見出しのスタイル設定、ページ番号の挿入など
   - 詳細な手順は「5. Word操作ガイド」を参照

### 4-2. 提出物

| # | 提出物 | 内容 |
|---|--------|------|
| 1 | **レポート本体**（Word文書） | 3〜4ページ、図表・参考文献含む |
| 2 | **対話チャットのリンク** | Manusのチャット画面右上「共有」から取得したリンク |

::: tip 対話チャットのリンク取得方法
1. Phase 5でManusに「対話サマリーを出力してください」と指示する
2. サマリーが出力されたら、チャット画面**右上の「共有」**をクリックする
3. 表示されたリンクをコピーして、提出時に一緒に提出する
:::

::: warning 提出前チェックリスト
- [ ] レポートが感想文ではなく、**分析と主張**を含んでいるか？
- [ ] 各主張に**根拠**（具体例・比較・データ等）が示されているか？
- [ ] 「はじめに」で立てた問いに「おわりに」で答えているか？
- [ ] **図表**が含まれ、番号とタイトルがついているか？
- [ ] **参考文献**が記載されているか？
- [ ] 文体は「である」調で統一されているか？
- [ ] **対話チャットのリンク**を取得済みか？
:::

## 5. レポートの体裁を整える — Word操作ガイド

ManusがWord形式で書き出したファイルを開き、以下の操作でレポートの体裁を整えましょう。第3回で学んだフォント・配置・字下げに加え、レポートに必要な操作を紹介します。

### 5-1. 画像を挿入する

作品のスクリーンショットや関連画像をレポートに入れましょう。

**操作手順：**

1. 画像を入れたい位置にカーソルを置く
2. **「挿入」タブ** → **「画像」** → **「このデバイス」** をクリック
3. 画像ファイルを選択して **「挿入」** をクリック

**画像のサイズ調整：**
- 画像をクリックして選択し、四隅のハンドル（○）をドラッグしてサイズを変更
- **Shift キーを押しながらドラッグ** すると縦横比を維持したまま拡大・縮小できる

**画像の配置：**
- 画像を選択した状態で、**「図の形式」タブ** → **「文字列の折り返し」** → **「行内」** を選択（本文の流れに沿って配置される）

::: tip スクリーンショットの撮り方
- **Windows**：`Windows + Shift + S` で画面の一部を切り取り → ペイントやWordに貼り付け
- **Mac**：`Command + Shift + 4` で画面の一部を切り取り → デスクトップに保存される
:::

### 5-2. 図のキャプション（番号とタイトル）をつける

レポートでは、すべての図に **番号とタイトル** をつけるのがルールです。

**操作手順：**

1. 画像の直下に新しい行を作る（画像の後ろにカーソルを置いて Enter）
2. **「図1 ○○の操作画面」** のように、図番号とタイトルを入力する
3. キャプションの行を **中央揃え** にする
4. フォントサイズを本文より少し小さく（例：9pt）すると見やすい

**良い例：**
```
図1 原神における元素反応のエフェクト表示
```

**悪い例：**
```
ゲーム画面1        ← 何の図か分からない
スクリーンショット  ← 番号がない
```

::: warning 本文中で図に言及する
図を置くだけでは不十分です。必ず本文中で「図1は〜を示している」のように言及してください。
:::

### 5-3. 見出しの番号付けとスタイル

レポートの各章には番号付きの見出しを設定します。

**操作手順：**

1. 見出しにしたい行にカーソルを置く
2. 「**1. はじめに**」「**2. 作品の概要**」のように番号を手入力する
3. **「ホーム」タブ** → **「スタイル」グループ** から **「見出し1」** を選択する

**見出しスタイルを使うメリット：**
- フォント・サイズ・配置が自動で統一される
- 目次を自動生成できる（長いレポートの場合）

::: tip 見出しのフォントを変更するには
「見出し1」スタイルを右クリック → 「変更」で、フォントをゴシック体（例：游ゴシック）に変更できます。
:::

### 5-4. ページ番号を入れる

複数ページのレポートには、ページ番号をつけましょう。

**操作手順：**

1. **「挿入」タブ** → **「ページ番号」** をクリック
2. **「ページの下部」** → 好みのデザインを選択（「番号のみ2」がシンプルでおすすめ）
3. ページ番号が自動で全ページに入る

### 5-5. 参考文献リストを作る

レポートの末尾に、参照した資料のリストを作成します。

**書き方のルール：**

```
参考文献

[1] 著者名. "タイトル", 出典（Webサイト名や雑誌名）, 年.
    URL（Webページの場合）, 閲覧日.
```

**Webサイトを引用する場合の例：**

```
参考文献

[1] 任天堂. "ゼルダの伝説 ティアーズ オブ ザ キングダム 公式サイト",
    https://www.nintendo.co.jp/zelda/totk/, 2026年3月閲覧.
[2] 山田太郎. "ゲームデザインにおけるフィードバックの役割",
    GamesStudies.jp, 2025.
```

**本文中での引用の仕方：**

```
× フロー理論では、没入感が生まれるとされている。
○ フロー理論では、没入感が生まれるとされている[2]。
```

::: tip 引用番号の入れ方
本文中の引用番号 `[1]` は半角で入力します。引用番号は文末の句点（。）の**直前**に置くのが一般的です。
:::

### 5-6. 体裁の最終チェック

レポートが完成したら、以下を確認しましょう。

- [ ] 見出しが**ゴシック体**、本文が**明朝体**になっているか
- [ ] フォントサイズが統一されているか（見出し：12〜14pt、本文：10.5pt）
- [ ] 段落の先頭が**字下げ**されているか
- [ ] 画像に**図番号とタイトル**がついているか
- [ ] 本文中で**図に言及**しているか
- [ ] 引用箇所に**引用番号**が振られているか
- [ ] 末尾に**参考文献リスト**があるか
- [ ] **ページ番号**が入っているか
- [ ] 文体が**「である」調**で統一されているか

## まとめ

今回は**AIを思考のパートナーとして活用するレポートの書き方**を学びました。

1. **テーマ選定** — 好きなメディア作品から分析の切り口を見つける
2. **構成設計** — 読者に伝わる論理的な構成をAIと一緒に設計する
3. **主張と根拠** — 「なぜそう言えるのか」を徹底的に考える
4. **下書き生成** — AIに書かせ、自分の言葉で仕上げる

> AIの力を借りることは「ずる」ではありません。大切なのは、**何を書くべきかを自分で考えること**。AIはその考えを言語化し、整理する道具です。考える力があれば、どんなテーマでもレポートが書けるようになります。

## 付録：レポートの体裁ルール

以下のルールは、レポートの体裁を整えるための基本事項です。レポートを仕上げる際の確認リストとして活用してください。

### 書式に関するルール

| # | ルール |
|---|--------|
| 1 | 見出しは**ゴシック体**、本文は**明朝体**を使う |
| 2 | フォントの種類・サイズは文書全体で**統一**する |
| 3 | 段落の冒頭は**字下げ**（1文字分）する |

### 文章に関するルール

| # | ルール | NG例 | OK例 |
|---|--------|------|------|
| 4 | 「私」「僕」→**「筆者」** | 私が調べた結果… | 筆者が調査した結果… |
| 5 | **「である」調**で統一 | 〜だと思います | 〜であると考えられる |
| 6 | **主観的表現**を避ける | すごく面白かった | 高い評価を受けている |
| 7 | **口語表現**を避ける | やっぱり〜だと思う | 〜であることが示唆される |
| 8 | **曖昧な表現**を避ける | 〜な気がする | 〜である可能性がある |
| 9 | 主語・述語のない**不完全な文**を避ける | 操作の快適性について。 | 操作の快適性について論じる。 |
| 10 | **問いかけ・依頼**をしない | ご存知だろうか？ | 〜が知られている。 |

### 構成に関するルール

| # | ルール |
|---|--------|
| 11 | 段落冒頭にはその段落の**概要がわかる文**を置く |
| 12 | 「おわりに」では**レポート全体を振り返り**、結論を述べる |
| 13 | 感想や随筆ではなく、**客観的な分析**として書く |

### 図表・引用に関するルール

| # | ルール | NG例 | OK例 |
|---|--------|------|------|
| 14 | 図の下に**番号とタイトル**をつける | グラフ1 | 図1 触感の大きさの平均値 |

# 第4回 AIと一緒にレポートを書く

## 今回の目標

- レポートと感想文の違いを理解する
- AIとの対話を通じて、レポートの「考え方」を体験する
- テーマ選定 → 構成設計 → 主張と根拠の検討 → 下書き生成の流れを身につける
- 授業外課題としてレポートを完成させる

---

## 1. レポートとは何か

### 1-1. 感想文とレポートの違い

| | 感想文 | レポート |
|--|--------|---------|
| **目的** | 自分が感じたことを伝える | 読者を「なるほど」と納得させる |
| **主語** | 「私は〜と感じた」 | 「〇〇は〜であると考えられる」 |
| **根拠** | なくてもよい | **必須**（データ・事例・比較など） |
| **構成** | 自由 | 序論→本論→結論の論理的な流れ |
| **文体** | ですます調でもOK | である調で統一 |

### 1-2. AI時代のレポートの書き方

AIは文章を書くことが得意です。しかし、**何について、どんな主張を、どんな根拠で書くか**を決めるのは人間の仕事です。

この授業では、従来の「体裁のルールを覚える」アプローチではなく、**AIと対話しながらレポートの思考プロセスを体験する**アプローチを取ります。

```
従来：ルールをたくさん覚える → 覚えきれない → 定着しない

今回：AIと対話しながら考える → 思考の流れを体験する
     → 体裁はAIに任せる → 考える力が残る
```

::: tip 体裁のルールは覚えなくていい？
レポートには確かに守るべき体裁ルールがあります（このページ末尾の付録を参照）。しかし、これらのルールは**AIに「このルールに従って整えてください」と渡せば一発で適用できます**。大事なのは、**何を書くかを自分で考えること**です。
:::

## 2. 今回のレポート課題

### テーマ

> **あなたが最も影響を受けたメディア作品（ゲーム・映像・音楽・アプリ・Webサービスなど）のインタラクションを分析し、なぜ人を惹きつけるのかを論ぜよ**

### 要件

| 項目 | 内容 |
|------|------|
| **テーマ** | 自分が強く影響を受けたメディア作品を1つ選ぶ |
| **内容** | 単なる感想ではなく、**分析**と**主張**を展開する |
| **分量** | Word文書、閲覧モードで3〜5ページ |
| **図表** | 作品のスクリーンショットや図を最低1つ含める |
| **参考文献** | 最低1つ以上の参考文献を引用する |
| **提出** | 授業内で指示された方法で提出 |
| **期限** | 次回授業日前日まで |

::: warning 「好きだから」だけでは不十分
「この作品が好きです。面白いです。」は感想文です。レポートでは「**なぜ**面白いのか」「**どのような仕組み**が人を惹きつけているのか」を分析し、根拠を示して論じる必要があります。
:::

## 3. AIとの対話でレポートを作る（授業内演習）

今日の授業では、**Claude**を使ってレポートの骨格を対話的に作り上げます。

### 3-1. 「レポート伴走AI」を準備する

1. [Claude](https://claude.ai/) にログインする
2. 新しいチャットを開く
3. 以下のリンクからテンプレートのテキストを**すべてコピー**し、チャットの最初のメッセージとして貼り付ける：

**伴走AIの指示テンプレート：**
[report-writing-skill.md](https://634nakajima.github.io/computer-literacy-A/report-writing-skill.md)

4. 貼り付けたテキストの末尾に「**この指示に従ってレポート作成を手伝ってください**」と追記して送信する

### 3-2. Phase 1 — テーマを選ぶ（10〜15分）

AIに「始めてください」と伝えると、以下のような質問が来ます：

> 「最近、時間を忘れて没頭したメディア作品は何ですか？」

**やること：**
- 自分が本当に好きな作品を正直に答える
- 「どこが好きか」「他の作品と何が違うか」をAIに聞かれるので、自分の言葉で答える
- AIが分析の切り口を提案してくれるので、一番しっくりくるものを選ぶ

::: details 選ぶ作品の例
- スマホゲーム（原神、プロセカ、モンスト、ポケモンGOなど）
- コンソールゲーム（ゼルダ、マイクラ、あつ森、スプラトゥーンなど）
- SNS・アプリ（TikTok、Instagram、Spotify、LINEなど）
- 映像作品（Netflix作品、YouTuber、MV、アニメなど）
- 音楽体験（ライブ配信、音楽ゲーム、AIプレイリストなど）
- Webサービス（Canva、Notion、Pinterest、Figmaなど）
:::

### 3-3. Phase 2 — 構成を設計する（10〜15分）

テーマが決まったら、AIがレポートの構成案を提案します。

**やること：**
- 提案された構成を読み、「この流れで読者に伝わるか？」を考える
- 気になる点があればAIに「ここはこう変えたい」と伝える
- 特に「**はじめに**で立てた問いに、**おわりに**で答えられているか」を確認する

### 3-4. Phase 3 — 主張と根拠を詰める（20〜25分）

ここが最も重要なフェーズです。各セクションについてAIと議論します。

**AIから聞かれること：**
- 「この章で一番伝えたいことは何ですか？」
- 「その主張の根拠は何ですか？」
- 「具体的にどの場面やシーンで、それが表れていますか？」

**やること：**
- 自分の言葉で答える（うまく言えなくてOK）
- AIが学術的な表現に変換してくれるので、意味が合っているか確認する
- 根拠が思いつかないときは正直に言う → AIがヒントやリサーチを手伝ってくれる

::: info 「根拠」の種類
- **具体例**：「このゲームでは、敵を倒すたびにエフェクトと効果音が出る」
- **比較**：「類似のゲームAではこの機能がないが、Bにはある。その差が体験に影響している」
- **データ・調査**：「この作品は発売から1年で1000万本を売り上げた」
- **理論・概念**：「フロー理論によれば、難易度とスキルのバランスが没入感を生む」
:::

### 3-5. Phase 4 — 下書きを生成する（10〜15分）

Phase 3で議論した内容をもとに、セクションごとに下書きを生成します。

**やること：**
- AIが生成した下書きを読み、「自分の言いたいことと合っているか」を確認する
- 合っていない部分は「ここはこうじゃなくて…」と修正を依頼する
- すべてのセクションが揃ったら、全体を通して読む

### 3-6. Phase 5 — 対話サマリーを出力する

最後に、AIに「対話サマリーを出力してください」と伝えます。以下が出力されます：

- 選んだ作品とテーマ
- レポートの構成と各セクションの要約
- 各セクションの主張と根拠
- 対話を通じて気づいたこと

このサマリーは、レポートを授業外で仕上げる際の設計図になります。

## 4. 授業外課題 — レポートを完成させる

### 4-1. やること

1. **下書きを自分の言葉で書き直す**
   - AIの出力をそのままコピペせず、自分の文章として自然になるように書き直す
   - 特に「考察」のセクションは自分の視点が重要
2. **図表を入れる**
   - 作品のスクリーンショットや関連画像を最低1つ含める
   - 図には番号とタイトルをつける（例：「図1 ○○の操作画面」）
3. **参考文献を追加する**
   - レポート内で参照した資料・Webサイトを文末にリストとして記載する
4. **体裁を整える**
   - 以下の付録「レポートの体裁ルール」をClaudeに渡し、チェックしてもらってもよい
   - 第3回で学んだWord書式設定を活用する

### 4-2. 提出物

| # | 提出物 | 内容 |
|---|--------|------|
| 1 | **レポート本体**（Word文書） | 3〜5ページ、図表・参考文献含む |
| 2 | **Claudeとの対話の共有リンク** | claude.aiの共有機能でURLを取得し提出 |

::: tip Claudeの対話を共有する方法
1. Claudeのチャット画面で、右上の **共有ボタン**（↗アイコン）をクリック
2. 「リンクを作成」をクリック
3. 生成されたURLをコピーして提出する

※ 共有機能が使えない場合は、Phase 5で出力した「対話サマリー」をWord文書の末尾に添付する形でもOKです。
:::

::: warning 提出前チェックリスト
- [ ] レポートが感想文ではなく、**分析と主張**を含んでいるか？
- [ ] 各主張に**根拠**（具体例・比較・データ等）が示されているか？
- [ ] 「はじめに」で立てた問いに「おわりに」で答えているか？
- [ ] **図表**が含まれ、番号とタイトルがついているか？
- [ ] **参考文献**が記載されているか？
- [ ] 文体は「である」調で統一されているか？
- [ ] Claudeとの対話の共有リンク（またはサマリー）が提出されているか？
:::

## まとめ

今回は**AIを思考のパートナーとして活用するレポートの書き方**を学びました。

1. **テーマ選定** — 好きなメディア作品から分析の切り口を見つける
2. **構成設計** — 読者に伝わる論理的な構成をAIと一緒に設計する
3. **主張と根拠** — 「なぜそう言えるのか」を徹底的に考える
4. **下書き生成** — AIに書かせ、自分の言葉で仕上げる

> AIの力を借りることは「ずる」ではありません。大切なのは、**何を書くべきかを自分で考えること**。AIはその考えを言語化し、整理する道具です。考える力があれば、どんなテーマでもレポートが書けるようになります。

## 付録：レポートの体裁ルール

以下のルールは、レポートの体裁を整えるための基本事項です。Claudeに「このルールに従ってレポートの体裁をチェックしてください」と渡すと、自動でチェック・修正ができます。

### 書式に関するルール

| # | ルール |
|---|--------|
| 1 | 見出しは**ゴシック体**、本文は**明朝体**を使う |
| 2 | フォントの種類・サイズは文書全体で**統一**する |
| 3 | 段落の冒頭は**字下げ**（1文字分）する |

### 文章に関するルール

| # | ルール | NG例 | OK例 |
|---|--------|------|------|
| 4 | 「私」「僕」→**「筆者」** | 私が調べた結果… | 筆者が調査した結果… |
| 5 | **「である」調**で統一 | 〜だと思います | 〜であると考えられる |
| 6 | **主観的表現**を避ける | すごく面白かった | 高い評価を受けている |
| 7 | **口語表現**を避ける | やっぱり〜だと思う | 〜であることが示唆される |
| 8 | **曖昧な表現**を避ける | 〜な気がする | 〜である可能性がある |
| 9 | 主語・述語のない**不完全な文**を避ける | 操作の快適性について。 | 操作の快適性について論じる。 |
| 10 | **問いかけ・依頼**をしない | ご存知だろうか？ | 〜が知られている。 |

### 構成に関するルール

| # | ルール |
|---|--------|
| 11 | 段落冒頭にはその段落の**概要がわかる文**を置く |
| 12 | 「おわりに」では**レポート全体を振り返り**、結論を述べる |
| 13 | 感想や随筆ではなく、**客観的な分析**として書く |

### 図表・引用に関するルール

| # | ルール | NG例 | OK例 |
|---|--------|------|------|
| 14 | 図の下に**番号とタイトル**をつける | グラフ1 | 図1 触感の大きさの平均値 |
| 15 | 本文中で**図の説明**をする | （図だけ置く） | 図1は〜を示している。 |
| 16 | 引用箇所に**引用番号**を振る | 〜が知られている。 | 〜が知られている[1]。 |
| 17 | 文末に**参考文献リスト**を作る | [1] 論文タイトル | [1] 著者名. "タイトル", 出典, 年. |

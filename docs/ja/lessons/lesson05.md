## 1. SD法とは何か

### 1-1. 感性評価とSD法の考え方

私たちは毎日、さまざまなものから印象を受け取っています。あるロゴを見て「かっこいい」と感じたり、ある音楽を聴いて「温かい」と感じたりするのは、言葉にしにくい感覚です。

**SD法（Semantic Differential Method）** は、こうした**感覚・印象を数値で測定する手法**です。1957年にアメリカの心理学者チャールズ・オズグッドが開発し、現在も製品デザイン・UI/UX評価・マーケティング・建築・音楽研究など幅広い分野で使われています。

### 1-2. SD法の仕組み

SD法では、**反対の意味を持つ形容詞ペア（両極尺度）** を複数用意し、評価対象がどちら寄りかを評定します。

**例：あるフォントを見て**

```
明るい  [1] [2] [3] [4] [5]  暗い
軽い    [1] [2] [3] [4] [5]  重い
好き    [1] [2] [3] [4] [5]  嫌い
```

- **1** = 左の形容詞にとても当てはまる
- **2** = 左の形容詞にやや当てはまる
- **3** = どちらでもない・中間
- **4** = 右の形容詞にやや当てはまる
- **5** = 右の形容詞にとても当てはまる

### 1-3. なぜ芸術学部で重要なのか

デザイン・アート・エンタテインメントの分野では、作品やプロダクトが人にどのような印象を与えるかを**客観的に把握する**ことが重要です。「なんとなくいい」ではなく、**「どの側面でどのくらい評価されているか」** をデータで示すことができるようになります。

::: tip SD法の活用例
- 商品パッケージの改善前後の印象変化測定
- Webサイトやアプリのデザイン評価（UI/UX）
- 音楽・映像作品の感情的反応の分析
- 空間・インテリアデザインの評価
- ブランドロゴのイメージ調査
:::

::: info サンプルの色について
今回提示しているサンプルA〜Fは、フォントだけでなく**配色も互いに異なります**。そのため厳密には、評定値には**フォントの形そのものの印象**と**色から受ける印象**の両方が含まれています。本来のSD法調査では、フォントだけを比較したい場合は配色を統一しますが、今回は印象の幅を広げる目的であえて色も変えています。考察するときはこの点を意識してください。
:::

## 3. Excel を起動する

### 3-1. Excel の基本画面

1. デスクトップまたはスタートメニューから **「Excel」** を起動する
2. **「空白のブック」** をクリックして新規ファイルを作成する

Excelの画面は大きなマス目（セル）でできています。

| 名称 | 説明 |
|------|------|
| **セル** | 一つひとつのマス目。データを入力する場所 |
| **列（Column）** | 縦方向の並び。A, B, C … のアルファベットで表示 |
| **行（Row）** | 横方向の並び。1, 2, 3 … の数字で表示 |
| **セル番地** | 列と行の組み合わせ（例：B3 = B列3行目） |
| **数式バー** | 選択中のセルの内容を表示・編集する場所 |

### 3-2. セルへの入力と移動

| 操作 | 方法 |
|------|------|
| セルを選択 | クリック |
| 入力確定して下へ移動 | **Enter** キー |
| 入力確定して右へ移動 | **Tab** キー |
| 入力をキャンセル | **Esc** キー |
| セルを編集 | **F2** キーまたはダブルクリック |

## 4. データ入力シートを作成する

### 4-1. ヘッダー行を入力する

以下の通りにセルを入力してください。

| セル | 入力内容 |
|------|----------|
| **A1** | （空白のまま） |
| **B1** | 明るい↔暗い |
| **C1** | 軽い↔重い |
| **D1** | 親しみやすい↔近寄りがたい |
| **E1** | 個性的↔平凡 |
| **F1** | 洗練↔野暮 |
| **G1** | 温かい↔冷たい |
| **H1** | 好き↔嫌い |
| **I1** | 平均 |

::: tip 列幅を広げるには
列番号の境界（A列とB列の間など）にカーソルを合わせると、カーソルが左右の矢印に変わります。その状態で**左右にドラッグ**すると、好きな幅に調整できます。
:::

| セル | 入力内容 |
|------|----------|
| **A2** | サンプルA |
| **A3** | サンプルB |
| **A4** | サンプルC |
| **A5** | サンプルD |
| **A6** | サンプルE |
| **A7** | サンプルF |
| **A9** | 項目平均 |

### 4-3. 自分の評定データを入力する

評定用紙を見ながら、自分の回答（1〜5の数値）を入力します。

- **B2〜H7** の範囲に、各サンプル×各項目の評定値を入力

**入力例（イメージ）：**

|  | 明暗 | 軽重 | 親密 | 個性 | 洗練 | 温冷 | 好嫌 |
|--|------|------|------|------|------|------|------|
| A | 2 | 2 | 2 | 3 | 4 | 2 | 1 |
| B | 3 | 4 | 4 | 2 | 2 | 4 | 4 |

::: warning 入力できる値は1〜5のみ

## 5. 基本統計を計算する

### 5-1. AVERAGE関数で各サンプルの平均を求める

**I2セル** に、サンプルAの7項目の平均を計算する式を入力します。

```
=AVERAGE(B2:H2)
```

**入力手順：**
1. **I2** をクリック
2. `=AVERAGE(B2:H2)` と入力
3. **Enter** で確定

数値が表示されたら成功です。

**I3〜I7 にも同じ式を入力する（オートフィル）：**
1. **I2** を選択する
2. セルの右下角の小さな■（フィルハンドル）にカーソルを合わせる
3. カーソルが **＋** の形になったら、**I7 まドラッグ**する

::: tip オートフィルとは
数式を隣接するセルにコピーする機能です。行番号が自動的にずれて、I3には `=AVERAGE(B3:H3)` が入ります。
:::

### 5-2. AVERAGE関数で各項目の平均を求める

**B9セル** に、「明るい↔暗い」の6サンプル平均を計算します。

```
=AVERAGE(B2:B7)
```

同様に **C9〜H9** まで、それぞれの列の平均をオートフィルで入力します。

### 5-3. MAX・MIN関数で最大値・最小値を求める

**B11セル** に以下を入力してみましょう。

```
=MAX(B2:B7)
```

**B12セル** に：

```
=MIN(B2:B7)
```

これで「明るい↔暗い」の評定の中で、最も「明るい（1に近い）」と感じたサンプルと、最も「暗い（5に近い）」と感じたサンプルのスコアがわかります。

::: info 関数の書き方のルール
- 必ず **`=`（イコール）** から始める
- 関数名は大文字・小文字どちらでもOK（Excelが自動で変換）
- 範囲は **`開始セル:終了セル`** で指定
:::

## 6. データを並べ替える

並べ替えを使うと、「どのサンプルが最も好きか」などをひと目で確認できます。

### 6-1. 「好き↔嫌い」スコアで並べ替える

1. データ範囲（**A1〜I7**）を選択する
2. **「データ」タブ** → **「並べ替え」** をクリック
3. 「列」を **「好き↔嫌い（H列）」** に設定
4. 「順序」を **「小さい順」** に設定（1＝好き が上に来る）
5. **「OK」** をクリック

「好き↔嫌い」スコアが小さい（＝好きな）順にサンプルが並び替わります。

### 6-2. 並べ替えを元に戻す

**Ctrl + Z** で取り消せます。または「サンプルA〜F」の順序を保持したい場合は、A列（サンプルラベル）で昇順ソートすれば元に戻ります。

## 1. クラス平均表を作る

前回の授業で全員がフォームに入力したアンケート結果を使って、**クラス全体の平均値**を計算する集計表をこれから自分で作ります。

### 1-1. 回答ファイルを開く

教員から配布された回答ファイル（`フォント印象評価アンケート（回答）.xlsx` など）を開きます。

シート **「フォームの回答 1」** を見てください。1行目に各サンプル×評定項目のヘッダー、2行目以降にクラスメイト一人ずつの回答が並んでいます。

| 列の位置 | 内容 |
|----------|------|
| A列 | タイムスタンプ |
| **B〜H列** | サンプルA の7項目（明るい←→暗い … 好き←→嫌い） |
| **I〜O列** | サンプルB の7項目（ヘッダー末尾に「2」が付く） |
| **P〜V列** | サンプルC の7項目（末尾「3」） |
| **W〜AC列** | サンプルD の7項目（末尾「4」） |
| **AD〜AJ列** | サンプルE の7項目（末尾「5」） |
| **AK〜AQ列** | サンプルF の7項目（末尾「6」） |

### 1-2. 新しいシートを追加する

集計表を作るための空のシートを追加します。

1. ウィンドウ下部のシートタブの右にある **「＋」ボタン** をクリック
2. 追加されたシートのタブをダブルクリックし、名前を **「クラス平均」** に変更

### 1-3. 集計表の枠を作る

「クラス平均」シートに以下を入力します。1行目がヘッダー、A列がサンプル名です。

|  | A | B | C | D | E | F | G | H |
|--|---|---|---|---|---|---|---|---|
| **1** |  | 明暗 | 軽重 | 親密 | 個性 | 洗練 | 温冷 | 好嫌 |
| **2** | サンプルA |  |  |  |  |  |  |  |
| **3** | サンプルB |  |  |  |  |  |  |  |
| **4** | サンプルC |  |  |  |  |  |  |  |
| **5** | サンプルD |  |  |  |  |  |  |  |
| **6** | サンプルE |  |  |  |  |  |  |  |
| **7** | サンプルF |  |  |  |  |  |  |  |

B2〜H7 のセルには、これから AVERAGE 関数で平均値を入れていきます。

### 1-4. AVERAGE関数で平均値を計算する

`AVERAGE` 関数は、指定した範囲の **平均値**を計算する関数です。

```
=AVERAGE(範囲)
```

**サンプルA の「明暗」平均（セル B2）：**

1. 「クラス平均」シートの **B2** セルを選択
2. `=AVERAGE(` と入力
3. シートタブで **「フォームの回答 1」** をクリック
4. **B列のヘッダー（B）の文字部分をクリック** すると、B列全体（`'フォームの回答 1'!B:B`）が範囲指定される
5. `)` を入力して **Enter**

完成する式：

```
=AVERAGE('フォームの回答 1'!B:B)
```

::: tip 列全体（B:B）を指定する理由
B列の1行目は文字（ヘッダー）なので AVERAGE は自動で無視します。今後回答が追加されても範囲を直す必要がないので、**列全体を選択する方法**が一番ラクで安全です。
:::

**残りのセルに展開する**

B2 を入力したら、以下の表に従って各サンプル×各項目について同じ手順で式を入れます。

| シート上のセル | 参照する「フォームの回答 1」の列 |
|----------------|----------------------------------|
| サンプルA（行2） | B〜H列 |
| サンプルB（行3） | I〜O列 |
| サンプルC（行4） | P〜V列 |
| サンプルD（行5） | W〜AC列 |
| サンプルE（行6） | AD〜AJ列 |
| サンプルF（行7） | AK〜AQ列 |

::: tip オートフィルで横方向に一気にコピー
B2 に式を入れたら、**B2セルの右下のフィルハンドル（小さな緑の四角）を H2 までドラッグ**すると、C2〜H2 に式が自動でコピーされ、参照列が B→C→D…と1つずつズレます。これでサンプルA の7項目はあっという間に完了します。

ただし、サンプルB の式（I列以降を参照）は別のサンプルなので、I3 から新たに式を入れ直してください。
:::

### 1-5. 回答数を数える

最後に、**何人が回答したか**を表示します。

1. **A9** セルに `回答数` と入力
2. **B9** セルに以下の式を入力

```
=COUNT('フォームの回答 1'!B:B)
```

これで B列の数値（評定値）が入ったセル数＝回答者数 が表示されます。

::: tip COUNT と COUNTA の違い
- **COUNT** … 数値の入ったセルだけを数える
- **COUNTA** … 空白でないセル（文字も含む）すべてを数える

評定値（1〜5の数字）の列なので、ここでは `COUNT` を使います。
:::

### 1-6. 自分の評定とクラス平均を比べる

前回作成した自分のファイルも開き、2つのウィンドウを並べてみましょう。

- 自分の評定がクラス平均と似ているサンプルは？
- 大きく異なるサンプルは？

この「個人差」もSD法を使った研究の重要なテーマです。

## 2. 棒グラフを作成する — 「好き度」の比較

### 2-1. 棒グラフを挿入する

クラス平均シートの「サンプル名の列」と「好嫌の列」を選んでそのままグラフにします。別の表を作る必要はありません。

1. クラス平均シートで、**サンプル名の列**（例：A1〜A7、ヘッダー含む）を選択する
2. **Ctrl を押しながら**、**「好嫌」列**（例：H1〜H7、ヘッダー含む）を追加選択する
3. **「挿入」タブ** → **「グラフ」グループ** → **「縦棒/横棒グラフの挿入」** をクリック
4. **「集合縦棒」** を選択する

グラフが挿入されます。

::: tip 離れた範囲の選択
1つ目の範囲をドラッグで選択したあと、**Ctrl キーを押したまま**2つ目の範囲をドラッグすると、離れた2つの列を同時に選択できます。
:::

### 2-2. グラフを見やすく整える

**グラフタイトルを変更する：**
1. グラフ上部の「グラフタイトル」をダブルクリック
2. テキストを削除し、**「フォントへの好感度（クラス平均）」** と入力
3. グラフ外をクリックして確定

**軸ラベルを追加する：**
1. グラフをクリックして選択する
2. 右上に表示される **「＋」アイコン**（グラフ要素）をクリック
3. **「軸ラベル」** にチェックを入れる
4. 縦軸ラベルに **「評定値（1=好き ↔ 5=嫌い）」** と入力

::: tip グラフの読み方
スコアが **小さいほど「好き」**（1＝好き）で、大きいほど「嫌い」（5＝嫌い）です。棒が短いサンプルほどクラスに好まれています。
:::

**棒の色を変更する（オプション）：**
1. 棒グラフの棒をクリック（全棒が選択される）
2. 右クリック → **「データ系列の書式設定」**
3. **「塗りつぶし」** から好みの色を選ぶ

## 3. レーダーチャートを作成する — 印象プロフィール

棒グラフは「1項目の比較」に向いていますが、**7項目すべてを同時に見る**にはレーダーチャート（クモの巣グラフ）が便利です。

### 3-1. レーダーチャートの理解

レーダーチャートは、複数の軸を放射状に配置し、各軸上の値を結んで多角形を描いたグラフです。

- 多角形が **大きい** → 全体的に「高評定（右の形容詞寄り）」
- 多角形が **小さい** → 全体的に「低評定（左の形容詞寄り）」
- **形の歪み** → 特定の項目だけ突出している

### 3-2. 1サンプルのレーダーチャートを作る

まず、**サンプルA** の全7項目のプロフィールを可視化します。

**データの選択：**
1. クラス平均シートで、サンプルAの行（評定項目のヘッダー行 + サンプルAの値の行）を選択
   - ヘッダー行（B1〜H1：「明暗」〜「好嫌」）を選択
   - **Ctrl を押しながら** サンプルAの行（B2〜H2）を追加選択

**グラフ挿入：**
1. **「挿入」タブ** → **「ウォーターフォール、じょうごグラフ…」** の横の **「その他のグラフ」**
2. または **「すべてのグラフ」** → **「レーダー」** → **「レーダー」** （塗りつぶしなし）を選択
3. OK をクリック

### 3-3. 複数サンプルを重ねて比較する

対照的な印象を持つ2〜3サンプルを選んで重ね合わせると、違いが一目でわかります。ここではサンプルBを追加する手順を示します。

**データ系列を追加する：**

1. グラフを右クリック → **「データの選択」**
2. 左側の **「凡例項目（系列）」** リストの下にある **「＋追加」**（または **「追加」**）ボタンをクリック
3. 「系列の編集」ダイアログが開く

**系列名（サンプル名）を指定する：**

4. 「系列名」欄の **右端のセル参照アイコン**（小さな↑のついた表マーク）をクリック
5. 「クラス平均」シートで **`サンプルB` と書かれたセル（A3）** をクリック
6. **Enter** で確定（ダイアログに戻る）

**系列値（評定データ）を指定する：**

7. 「系列値」欄の **右端のセル参照アイコン** をクリック
8. 「クラス平均」シートで **サンプルBの評定値の範囲（B3〜H3）** をドラッグ（初期値の `={1}` はドラッグした範囲で自動的に上書きされる）
9. **Enter** で確定
10. ダイアログの **「OK」** をクリック
11. 「データソースの選択」画面に戻ったら、もう一度 **「OK」**

サンプルAとサンプルBの2つの多角形が重なって表示されます。同じ手順を繰り返せば、3つめ以降のサンプルも追加できます。

::: tip 比較のヒント
- 「好き度」が最も高かったサンプルと最も低かったサンプルを比べてみましょう
- 形がまったく異なる場合、どの項目が特に違うでしょうか？
:::

## 4. 自分とクラスを比べる

### 4-1. 自分の評定でレーダーチャートを作る

前回のファイル（自分の評定データ）で同じ手順でレーダーチャートを作り、**クラス平均のレーダーチャートと見比べて**みましょう。

**着目するポイント：**

- あなたが高く評価したサンプルをクラス全体も高く評価していた？
- 「個性的↔平凡」など特定の項目で個人差が大きかった項目はどれか？

### 4-2. 考察をセルに書く

グラフの下のセルに、以下の内容で気づきを書いてみましょう。

```
＜考察＞
・クラスで最も好まれたのはサンプル○○で、評定平均は○○だった。
・自分の評定と最も異なったのはサンプル○○の○○（項目名）だった。
・レーダーチャートから、サンプル○○は「洗練された印象」が強く、
  サンプル○○は「親しみやすい印象」が強いことが読み取れた。
```

::: info 考察するときの注意：色の影響
前回提示したサンプルA〜Fは、フォントだけでなく**配色も互いに異なっています**。そのため、得られた評定値は**フォントの形そのものの印象**だけでなく、**色から受ける印象**も含んだ結果になっています。たとえば「温かい↔冷たい」のスコアは、書体の特徴と同じくらい、文字や背景の色にも左右されている可能性があります。考察を書くときは、「この差はフォントの違いによるものか、それとも色の違いも影響しているか」を意識すると、より深い分析になります。
:::

## 5. SD法の可能性と限界

### 5-1. SD法が活躍する場面

| 分野 | 使われ方 |
|------|----------|
| **プロダクトデザイン** | 製品・パッケージの印象評価、改良前後の比較 |
| **グラフィックデザイン** | ロゴ・ポスター・フォント選定の根拠づくり |
| **UI/UXデザイン** | Webサイト・アプリの使い心地の評価 |
| **音楽・映像** | 楽曲や映像作品が伝える感情・雰囲気の分析 |
| **建築・空間** | インテリア・都市空間の快適性・印象評価 |
| **マーケティング** | ブランドイメージ調査、競合比較 |

### 5-2. 注意すべき点

::: warning SD法の限界
- 評定者の文化・年齢・性別・経験によって結果が変わる
- 形容詞ペアの選び方が結果に影響する（適切なペアを選ぶのが難しい）
- 「真ん中（3）ばかり選ぶ」傾向（中心化傾向）に注意
- サンプル数が少ないと統計的に信頼できない
:::

これらの問題を意識しながらデータを解釈することが、研究者・デザイナーとして重要なスキルです。

## まとめ

2回にわたるSD法演習で学んだこと：

1. **SD法の理論** — 形容詞ペアで印象を数値化する手法（デザイン・マーケティング分野で広く使用）
2. **データ入力と集計** — AVERAGE・MAX・MIN関数による基本統計
3. **棒グラフ** — カテゴリ間の数値比較に最適
4. **レーダーチャート** — 多変量の印象プロフィールを一目で可視化
5. **考察の書き方** — グラフから客観的に読み取り、自分の言葉で表現する

> 感覚・感性は、データにすることで**共有・比較・改善**できるようになります。
> これがデザインや芸術をより多くの人に届けるための重要な視点です。
